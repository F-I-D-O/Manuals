
# Meta Tags
[Wikipedia](https://en.wikipedia.org/wiki/Meta_element)

The `<meta>` tag is used to specify metadata about the page.

## Open Graph Protocol
[homepage](https://ogp.me/)

The Open Graph protocol is specification for meta tags that can be used to describe the page as an object on the web.

Open Graph protocol meta tags:

- `og:title`: title of the page
- `og:type`: type of the page, e.g., `website`, `article`, `book`, `video`
- `og:url`: canonical URL of the page
- `og:image`: image representing the page. Unlike favicon, this image should be much larger. Typically, it is used in the preview of the page in social networks or IM clients like Slack or WhatsApp.

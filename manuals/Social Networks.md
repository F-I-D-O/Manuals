# Instagram

## Posts
Posts can be added both from computer and from mobile device. However, there are differences:

| Feature | Mobile | Web |
| - | - | - |
| Image limit | 20 images per post | 10 images per post |
| Aspect ratio | 1:1, 4:5, mixed (original) | 1:1, 4:5, 16:9, mixed (original) |
| Combined video and images | yes | only if the video is shorter than one minute |
| Share to Facebook too | yes | yes |
| Music | yes | no |

For the **mobile app**, the workflow is now (as of 2026-08-24):

1. First screen: just select the images and videos
2. Second screen:
    1. choose the resolution (1:1, 4:5, mixed)
    1. choose the crop for each image. This is done by moving two fingers simultaneously on the image.
        - Note that there is a limit for two narrow/wide images, so cropping may be necessary even for the *mixed* resolution.
1. Third screen:
    1. add music
    1. setup Facebook sharing
    1. text

For the **desktop browser**, the workflow is now (as of 2026-10-13):

1. Select the files. Use the File Selector instead of dragging and dropping if you want to keep the order.
1. First screen: 
    1. choose the resolution (mixed ("original"), 1:1, 4:5, 16:9)
    1. reorder the images if necessary
1. Second screen - skip (just filters and other images adjustments)
1. Third screen

## Automatic sharing to Facebook
Automatic sharing to Facebook is available for both posts and stories. However, **Facebook sharing is incompatible with the schedule feature**.
